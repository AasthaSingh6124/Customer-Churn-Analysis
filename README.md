📊 Customer Churn Analysis Dashboard | Power BI

This project analyzes customer churn for a telecom company using Power BI.
The objective is to identify key churn drivers, high-risk customer segments, and quantify the revenue impact of churn using interactive dashboards.

🔍 Dataset

Telco Customer Churn Dataset:
~7,000 customer records
Demographics, services, contracts, billing, and churn status

🎯 Project Objectives

Calculate overall churn rate
Identify key churn drivers
Segment customers based on churn risk
Analyze service usage and billing behavior
Quantify revenue lost due to churn

📈 Key Insights

Overall churn rate is ~27%
Highest churn among month-to-month, early-tenure customers
Fiber optic users churn more than DSL users
Customers with fewer services churn significantly more
Churn drops from 46% (1 service) to 5% (6 services)
Electronic check users show the highest churn
Customer churn results in significant revenue loss

🛠 Tools & Skills

Power BI
DAX (Churn Rate, Revenue Impact, Risk Segmentation)
Power Query (Unpivot, Data Cleaning)
Data Modeling & Visualization

📊 Dashboard Features

KPI cards for churn & revenue
Stacked bar charts for segment comparison
Matrix heatmaps for churn concentration
Box plots for charge distribution
Waterfall chart for revenue impact
Interactive slicers for filtering

📌 Business Value

This dashboard helps businesses:
Identify high-risk customers early
Reduce churn through targeted retention strategies
Protect revenue by focusing on high-impact segments
